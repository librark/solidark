# Changelog

All notable changes to Solidark will be documented in this file.

## 0.1.0 - Unreleased

- Initial external release candidate.
- Declarative Web Component API for CAD model trees.
- In-memory descriptor kernel and OpenCascade.js-backed runtime kernel.
- Built-in primitives, transforms, boolean operations, sketch/profile features,
  styling, viewer helpers, and CAD/mesh export helpers.
- Robot extension API for deterministic robot definition exports.
- Public package surface limited to documented vertical entrypoints.
- CDN bootstrap entrypoint for standalone HTML examples through unpkg.
